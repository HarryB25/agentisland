# AgentIsland Collaboration Notes

## Branching And Publishing

- Treat `develop` as the working branch for ongoing, non-milestone changes.
- Push to GitHub `main` only after a successful, staged milestone update.
- Before pushing to `main`, verify the app builds/runs successfully and confirm the working tree only contains intended changes.
- Do not push incomplete, experimental, or unverified work to `main`; keep that work on `develop`.
